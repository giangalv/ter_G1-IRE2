# tools/

Small scripts used to map the robot. Python 3, standard library + `numpy`
(+ `rclpy` and the `unitree_api` / `unitree_hg` messages for `slam_call.py`, `sport_call.py` and `remote_events.py`, which are run
**without** `-I` so the ROS environment is found). Run them with
`python3 -I` where it says so, so the current directory cannot shadow modules.

| Script | What it does | Writes to the robot? |
|---|---|---|
| `modbus_probe.py HOST` | Reads the main registers of one hand (Modbus function 0x03 only) | no |
| `modbus_capture.py SECONDS PREFIX` | Reads bytes 0…5999 of **both** hands repeatedly and saves `PREFIX_210.npz` / `PREFIX_211.npz` (`x[:, k]` = word at byte `2k`) | no |
| `tactile_probe.py HOST [SECONDS] [--map]` | Live read-only view of the 17 tactile regions (sum / max / active cells, optional heat map) | no |
| `cam_cover_test.py LEAD CYCLES` | Left/right test for the palm cameras: streams thumbnails from the Jetson over SSH while the laptop beeps; needs `G1_PW`, `play` (sox) and `askpass.sh` | no (opens the two video nodes) |
| `lidar_listen.py [SECONDS]` | Subscribes to `/utlidar/*_livox_mid360`, prints rates, cloud layout and valid-point stats, saves one cloud to `lidar_cloud.npz` | no |
| `g1_inventory.sh` | Read-only inventory of the Jetson for docs/09: module, JetPack, CPU, memory, power mode, storage, USB, network, Bluetooth, audio, Unitree modules; MACs masked; needs `G1_PW` | no |
| `slam_call.py API_ID 'JSON'` | Sends **one** `unitree_api` request to `/api/slam_operate`; `--dry` only checks that someone listens | **yes** (one SLAM request) |
| `sport_call.py get\|watch SECONDS\|fsm 1\|4\|501\|damp\|stop\|vel VX VY W DURATION` | ONE request to the locomotion service `/api/sport` (docs/08): `get` reads FSM id/mode/stand height (7001/7002/7005), `watch` prints FSM changes, `fsm` sets the FSM id (only 1, 4 and 501; **never 500** on this 29-motor robot), `damp` = `fsm 1`, `stop` = velocity 0, `vel` = velocity capped at 0.2 / 0.1 m/s, 0.3 rad/s, ≤ 1 s. Everything but `get`/`watch` is refused unless `G1_ALLOW_MOTION=1`; aborts without sending if nobody answers; prints each round-trip time | **yes** (FSM id or velocity, only with `G1_ALLOW_MOTION=1`; `get`/`watch` are queries) |
| `g1_env.sh cable\|wifi` | **Source it** (`source tools/g1_env.sh cable`): the DDS environment of docs/01 (domain 0, CycloneDDS profile of `ros2_ws/src/g1_viz/config`, ROS 2 Humble + a workspace with the Unitree messages: `$G1_WS_INSTALL` or `ros2_ws/install`). Changes only the current shell | no |
| `keyboard_teleop.py [--dry] [--vx --vy --w --hold --first-hold]` | Keyboard teleop through `/api/sport` (docs/08): starts **disarmed**, `r` arms, `w/s/a/d/q/e` move while the terminal repeats the key (first press 0.6 s, each repeat 0.2 s), `Enter` or space stops; **the robot's state by keys held 3 s**: `z` zero torque, `p` damping, `l` locked standing, `g` regular mode (only from the state the remote uses; `p` from any). Needs `G1_ALLOW_MOTION=1`, a real terminal and **the Unitree remote switched on** (it refuses to start otherwise, it is the backup); sends velocity only in FSM 501 with `/lf/lowstate` alive and no tilt; caps 0.2 / 0.2 m/s, 0.3 rad/s (the speed level starts at 50 %, `3` = full cap; sideways steps only from 0.2 m/s); `--dry` sends only the FSM poll | **yes** (velocity 7105 and FSM changes 7101, only with `G1_ALLOW_MOTION=1`) |
| `remote_events.py [SECONDS] [--quiet]` | Passive event stream for a session with the Unitree remote: the keys that reach the robot (decoded from `/lf/lowstate.wireless_remote`), FSM id changes, and (without `--quiet`) stick use and leg bursts; sends nothing | no |
| `g1_service.py list\|on NAME\|off NAME` | Lists / switches the robot's services (the app's Service Status page, e.g. `lidar_driver`) with ONE `unitree_api` request to `/api/robot_state/request` (api 1003 list, 1001 switch); `--dry` only checks that someone listens; `off` refuses safety services | **yes** (`on`/`off`; `list` is a query) |
| `g1_up.sh` | After every robot boot: waits for the service manager, switches `lidar_driver` on if it is off and starts the RealSense driver if it is not running (`G1_PW` = Jetson password, `G1_CAMERA=false` for LiDAR only); idempotent | **yes** (one service switch, the Jetson driver) |
| `tactile_session.py HOST SECS LABEL...` | Voice-guided press test: a 2 s baseline, then for every LABEL it speaks the cue (Italian, `spd-say`), beeps (`play`/sox), records `SECS` and prints the regions that rose above the baseline, with the peak cell | no |
| `slide_scan.py HOST SECS LABEL ...` | Same for a slow slide of a finger along the hand: prints, every 0.5 s, the active region, rows and columns | no |
| `open_hand.py HOST [--keep-thumb]` | Opens **one** hand slowly (`--keep-thumb`: only the four fingers): `SPEED_SET` 300, `ANGLE_SET` 1000 (thumb rotation kept), aborts and holds if `ERROR` ≠ 0 or `FORCE_ACT` > 700, restores `SPEED_SET` 1000 | **yes** (`SPEED_SET`, `ANGLE_SET`) |
| `close_hand.py HOST [destra\|sinistra] [--go]` | Closes **one** hand slowly to a relaxed fist (fingers 100, thumb bend 200): `SPEED_SET` 300, `ANGLE_SET`, aborts and holds if `ERROR` ≠ 0 or `FORCE_ACT` > 700, restores `SPEED_SET` 1000; reads only without `--go` | **yes** with `--go` (`SPEED_SET`, `ANGLE_SET`) |
| `thumb_test.py HOST [destra\|sinistra] [--go]` | Moves only one **thumb channel** (rotation, or bend with `--channel=bend`) of one hand through the set values of `--steps` and back, `SPEED_SET` 300, other channels held; stops on contact or stall and backs off, aborts and holds if `ERROR` ≠ 0 or `FORCE_ACT` > 700; reads only without `--go` | **yes** with `--go` (`SPEED_SET`, `ANGLE_SET`) |
| `start_app_video.sh start\|stop\|status` | **Runs on the Jetson.** Makes the phone app show the head camera after a boot: stops the stock `video_hub_pc4`, runs a patched copy in `/tmp` that streams on the right NIC (see docs/01) | **yes** (stops/starts a Unitree service; nothing persistent) |
| `realsense_ros2.sh install\|start\|stop\|status\|check\|log\|stream [name=value ...]\|stack [254\|old]\|autostart on\|off\|status` (+ `realsense_ros2_remote.sh` and `realsense_encoder_node.py`, which it sends to the Jetson) | Installs and runs the RealSense D435i ROS 2 driver on the Jetson (own DDS domain 42) with a supervisor that restarts it within ~20 s when the camera is lost (and when it streams 0 frames), `stack` picks librealsense 2.54.2 or 2.50.0, and an encoder node (colour JPEG, depth PNG, rates changeable with `stream`) for the Wi-Fi, see docs/06 and docs/07. `start` stops the app video (`video_hub_pc4`) because the camera cannot be shared; an optional `~/g1_realsense/extra_args` (one line of launch args) is added to every start, supervisor restarts included | **yes** (files in `~/g1_realsense`, stops a Unitree service; nothing system-wide) |
| `realsense_build_254.sh` | **Runs on the Jetson** (sources copied from the laptop first, see its header). Builds librealsense 2.54.2 + realsense-ros 4.54.1 in `~/g1_realsense_254` (about 1 h, no root); `realsense_ros2.sh stack 254` selects it, docs/06 | **yes** (files in `~/g1_realsense_254`, heavy CPU for an hour) |
| `g1_wifi.sh up\|down\|status\|env` (+ `wifi_dds_relay.py`, which it runs on the Jetson) | Work over the robot's own Wi-Fi AP instead of the cable: Jetson route/proxy ARP/forward rules + DDS discovery relay, laptop profile `g1-ap`; `down` undoes it. docs/07.
| `lidar_slim.sh start\|stop\|status\|log` (+ `lidar_slim_node.py`, which it runs on the Jetson) | Lighter LiDAR cloud for the Wi-Fi: a filter on the Jetson drops the empty points, x=y=z=0 (38 %) and the head's own returns, publishes `/g1/lidar/slim` (60 % of the bytes, 2.6 MB/s instead of 4.4); `G1_LIDAR_TOPIC=/g1/lidar/slim` for `viz_real.sh`. docs/07. | **yes** (a user-level process and files in `~/g1_lidar_slim` on the Jetson, no root, the process is gone at the next boot) |
| `lab_record.sh start [NAME]\|stop\|status\|list\|pull NAME [DEST]\|rm NAME` | Records a rosbag ON the Jetson while the robot walks free (no cable/Wi-Fi), copies it out afterwards over the cable: bag `lidar` (domain 0: Mid-360 cloud with per-point time/ring, IMU in g, odometry) + bag `camera` (domain 42: D435i raw 15 Hz, or the compressed pair with `G1_BAG_RAW=false`). ~110 MB/min LiDAR, ~1.4 GB/min raw camera; copy ~70 MB/s. Needs `lidar_driver` on. | **yes** (user-level recorders and files in `~/g1_bags` on the Jetson, subscribe only, no root) |
| `hand_cameras_ros2.sh install\|start\|stop\|status\|log\|autostart on\|off\|status` (+ `hand_cameras_ros2_remote.sh`) | Runs the palm cameras' ROS 2 node (`ros2_ws/src/g1_hand_camera`) on the Jetson in DDS domain 42, JPEG only, a camera is opened only while somebody subscribes to it (`on_demand`), see docs/03 | **yes** (files in `~/g1_hand_cameras`, opens a camera when subscribed) |
| `askpass.sh` | `SSH_ASKPASS` helper: prints `$G1_PW` so `ssh` can log in non-interactively | — |

Examples:

```bash
python3 -I tools/modbus_probe.py 192.168.123.211            # right hand
python3 -I tools/modbus_capture.py 20 /tmp/hands            # both hands, 20 s
G1_PW=... python3 tools/cam_cover_test.py 15 4              # which camera is which
```

The password is never stored in the repo: pass it through the environment.
